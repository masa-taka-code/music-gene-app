# Loop Studio（リズム選別ツール）

音楽理論に基づいてループを自動生成し、聴いて評価しながら好みを学習させ、
ソング化・素材パッケージ化までをブラウザ単体で行うツールです。
Mac のデスクトップブラウザ（Safari / Chrome）での利用を想定したデザインです（狭い画面でも動作します）。

## 使い方

`rhythm-selector.html` をブラウザで直接開くだけで動作します（サーバー不要）。
Tone.js・JSZip・サンプル音源の読み込みにインターネット接続が必要です。

1. ジェネレーターでジャンル・キー・長さ（1/2/4/8/16小節、または秒数）を選ぶ
2. ▶（Space）で試聴し、★1〜5（数字キー）で評価して保存、✕（X）でスキップ
3. 右側のミキサーでパートごとの楽器・音量・パン・リバーブを調整（🔒で音色を固定）
4. ライブラリのループから「ソングビルダー」で曲を構成、またはオートパイロットで自動生成
5. 「書き出し」から WAV / ステム / MIDI / 販売用パッケージ（ZIP）を出力

### キーボードショートカット

| キー | 動作 |
|---|---|
| Space | 再生 / 停止 |
| 1〜5 | ★で評価して保存（保存済み表示中は評価の変更） |
| X / Delete | スキップ（好みでないことを学習） |
| R | 別の候補を生成（学習なし） |
| A / B, ← / → | A/B比較モードで試聴・勝者の選択 |
| ⌘E | WAV書き出し |
| ⌘S | ★3で保存 |
| ⌘, | 設定 |

## 主な機能

- **楽器**: ピアノ、エレピ、オルガン、ギター各種（ナイロン・スチール・クリーン・ミュート・歪み）、
  ベース各種（指弾き・ピック・スラップ・ウッド・シンセ）、ストリングス、ブラス、サックス、フルート、
  ビブラフォン、オルゴール、パッド、リード、内蔵シンセ。ドラムキットは5種類（スタンダード／アコースティック風／ローファイ／エレクトロ／808）
- **生成**: 7ジャンル（J-POP、Lo-fi、シティポップ、EDM、Trap、ロック、バラード）、王道進行・小室進行・カノン進行・丸サ進行など4コード以上の進行、
  7thコード、コード奏法（白玉・刻み・裏打ち・アルペジオ・ストローク等）、ベース奏法（ウォーキング・808等）、モチーフの反復と変化によるメロディ、
  4小節ごとのドラムフィル、スウィング、ゴーストノート、トラップのハイハットロール
- **長さ**: 1〜16小節、または秒数指定（BPMから小節数を自動計算）
- **学習**: ★評価・スキップ・A/B比較・販売数の記録から、ジャンル・テンポ帯・キー・進行・リズム・奏法・楽器の重みを学習（20%は探索のため完全ランダム）。「学習」タブで傾向を確認可能
- **ソングビルダー**: イントロ／Aメロ／Bメロ／サビ／間奏／アウトロを並べ、パートの抜き差しで展開を作成。キーとテンポはベースループに自動で揃え、セクションの変わり目にフィルを挿入
- **オートパイロット**: 学習した好みで大量の候補をスコアリングし、上位だけを保存。ソング化・AIによる曲名付け・ZIP書き出しまで自動化
- **AIアシスタント**（任意）: Claude API で曲名・説明文・検索タグの生成、ライブラリからのソング構成の提案
- **書き出し**: WAV（シームレスループ／リピート＋余韻、44.1/48kHz、16/24bit）、パート別ステム、マルチトラックMIDI（楽器の Program Change 付き）、
  販売用パッケージ（WAV＋ステム＋MIDI＋metadata.json＋README）

## 構成

- 生成ルールは `DEFAULT_RULES`（スクリプト冒頭）を差し替えるだけで変更可能。設定から外部JSONの読み込み・現在のルールの書き出しにも対応
- 保存データ・音色設定・学習した重み・APIキーはブラウザの `localStorage` に保存（端末内で完結）。旧バージョンで保存したループは自動で新形式に変換
- ライブラリは JSON で書き出し／読み込みでき、別の端末へ移せます

## 技術

- HTML + JavaScript 単一ファイル（ビルド不要）
- 音源エンジン: [Tone.js](https://tonejs.github.io/)（CDN）
- サンプル音源: FluidR3_GM サウンドフォント（[gleitz/midi-js-soundfonts](https://github.com/gleitz/midi-js-soundfonts) 経由で読み込み）
- ZIP: [JSZip](https://stuk.github.io/jszip/)（CDN）
- AI: [Anthropic TypeScript SDK](https://github.com/anthropics/anthropic-sdk-typescript)（使用時のみ jsDelivr から読み込み、モデルは `claude-opus-5`）

## 収益化・権利に関する注意

- **サンプル音源のライセンス**: FluidR3_GM は一般に MIT ライセンスとして配布されていますが、商用利用の前に配布元のライセンスを必ずご自身で確認してください。「内蔵」シンセとドラムは外部音源を使いません
- **APIキー**: ブラウザから Anthropic API に直接送信され、`localStorage` に保存されます。共有パソコンでは保存しないでください
- **配信サービスの規約**: 大量のAI生成楽曲の投稿を制限しているサービスがあります。投稿先の規約を確認し、人による選別・編集を加えることをおすすめします
