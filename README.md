# リズム選別ツール（フェーズ1）

音楽理論に基づいて3〜5秒（2小節・BPM 80〜140）のループをランダム生成し、
聴いて 👍保存 / 👎再生成 で選別するブラウザ単体のツールです。
保存したループは後のフェーズで曲に発展させる素材になります。

## 使い方

`rhythm-selector.html` をブラウザで直接開くだけで動作します（サーバー不要）。
インターネット接続は Tone.js の読み込みに必要です。

1. ▶再生でループを試聴
2. 👍保存で気に入ったループをライブラリに保存（同時に好みを学習）
3. 👎再生成で次の候補を生成（同時に好みを学習）
4. 「楽器」セクションの各チャンネルで音量・余韻・波形などを微調整可能
5. 保存したループはJSON／MIDIとして書き出し可能

## 構成

- ドラム・ベース・コードの3パートを音楽理論（スケール／トライアド）に基づいて生成
- 生成ロジック・再生・保存・好み学習（重み付け抽選、20%は完全ランダム）をそれぞれ独立した関数に分離
- 生成ルールは `DEFAULT_RULES`（ファイル冒頭）を差し替えるだけで変更可能。設定パネルから外部JSONファイルの読み込みにも対応
- 保存データ・音色設定・学習した重みはすべてブラウザの `localStorage` に保存（端末内で完結）

## 技術

- HTML + JavaScript 単一ファイル
- 音源: [Tone.js](https://tonejs.github.io/)（CDN読み込み）
- 外部サーバー・ビルド不要
